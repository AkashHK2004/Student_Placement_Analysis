# 🎓 Placement Readiness & Student Performance Analysis

## Project Overview
This project analyzes the academic and placement records of 10,000 students to uncover meaningful patterns in CGPA, aptitude scores, internship experiences, and final placement outcomes[cite: 1]. The goal is to identify the key drivers of successful campus placements and provide actionable insights for placement readiness[cite: 1].

## 🛠️ Tech Stack
* **Database & Querying:** SQL (CTEs, Window Functions, Aggregations, CASE statements)[cite: 1]
* **Data Processing & Analytics:** Microsoft Excel (Pivot Tables, Data Cleaning)[cite: 1]
* **Data Visualization:** Tableau Public (Interactive Dashboard Design)

## 🔍 Key Objectives & Workflow
1. **Data Cleaning & Structuring (Excel & SQL):**[cite: 1]
   * Processed raw dataset of 10,000 students by verifying data types and handling potential duplicates[cite: 1].
   * Standardized boolean flags (e.g., Extracurriculars, Placement Training) for accurate grouping[cite: 1].
2. **Exploratory Data Analysis (SQL & Excel):**[cite: 1]
   * Created Excel pivot tables and complex SQL aggregations to evaluate data[cite: 1].
   * Segmented students into CGPA brackets, revealing a sharp increase in placement rates for students with an 8.0+ CGPA[cite: 1].
   * Analyzed the compounding impact of multiple internships and aptitude test scores on placement success[cite: 1].
3. **Dashboard Development (Tableau):** 
   * Built an interactive Tableau dashboard combining CGPA performance, internship training impact, and skill gap comparisons into an executive grid layout.
   * Highlighted core metrics including placement percentage by CGPA, soft skills rating distributions, and the effect of placement training.
