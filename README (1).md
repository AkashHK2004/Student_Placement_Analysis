# 🎓 Placement Readiness & Student Performance Analysis

## Project Overview
This project analyzes the academic and placement records of 10,000 students to uncover meaningful patterns in CGPA, aptitude scores, internship experiences, and final placement outcomes. The goal is to identify the key drivers of successful campus placements and provide actionable insights for placement readiness.

## 🛠️ Tech Stack
* **Database & Querying:** SQL (CTEs, Window Functions, Aggregations, CASE statements)
* **Data Processing & Analytics:** Microsoft Excel (Pivot Tables, Data Cleaning)
* **Data Visualization:** Power BI

## 🔍 Key Objectives & Workflow
1. **Data Cleaning & Structuring (Excel & SQL):** 
   * Processed raw dataset of 10,000 students by verifying data types and handling potential duplicates.
   * Standardized boolean flags (e.g., Extracurriculars, Placement Training) for accurate grouping.
2. **Exploratory Data Analysis (SQL & Excel):** 
   * Created Excel pivot tables and complex SQL aggregations to evaluate data.
   * Segmented students into CGPA brackets, revealing a sharp increase in placement rates for students with an 8.0+ CGPA.
   * Analyzed the compounding impact of multiple internships and aptitude test scores on placement success.
3. **Dashboard Development (Power BI):** 
   * Built an interactive Power BI report to visualize the findings.
   * Highlighted core metrics including placement percentage by CGPA, soft skills rating distributions, and the effect of placement training.

## 📁 Repository Structure
* `placementdata.csv`: The dataset containing 10,000 student records.
* `placement_analysis.sql`: The SQL script used for data deduplication, cleaning, and aggregation queries.
* `Placement_Analysis_Dashboard.pbix`: The interactive Power BI report.
* `Dashboard_Screenshot.png`: A high-quality snapshot of the Power BI dashboard for quick viewing.
